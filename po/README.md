# Translations

English strings in the source code are the fallback language; no `en.po` is
needed. Translated `<language>.po` files will be added here through reviewed
Weblate synchronization pull requests. Generated `.pot` files are not tracked
in this repository; the current template is published in the
[Weblate buffer repository](https://github.com/yashjawale/cockpit-cron-weblate).
